## UML (documentation)

Ce dossier regroupe des diagrammes **UML** afin de documenter les principaux aspects de la plateforme : structure, flux, états.

### Sommaire

- `01-components.md` : vue composants (entrée HTTP → services → données → intégrations).
- `02-classes.md` : vue classes (entités clés et relations).
- `03-sequences.md` : vues séquence (flux critiques).
- `04-states.md` : vues états (statuts métier).
- `05-global-ia-components.md` : vue composants globale avec couche IA (chatbot, IA live, approbations).
- `plantuml/README.md` : versions **PlantUML** (fichiers `.puml` pour aperçu/export).
  - Inclut un fichier "tout-en-un" : `docs/uml/plantuml/99-all-in-one.puml`

### Rendu

Ces fichiers utilisent des blocs `mermaid` (rendu via l’aperçu Markdown).
Pour une prévisualisation UML “native” (PlantUML), utiliser `docs/uml/plantuml/`.
